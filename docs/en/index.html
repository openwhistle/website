At a glance

OpenWhistle at a glance

OpenWhistle is free, open source whistleblower software under the GPL-3.0. It suits employers with 50 or more workers, certain financial firms and public bodies that need an internal reporting channel under the EU Directive or the HinSchG. You run OpenWhistle with Docker on your own server, in the EU too; you pay for the server and its operation, not for a licence.

OpenWhistle facts
LicenceGPL-3.0, source code public on GitHub
Price€0, no paid tier, no subscription
HostingSelf-hosted only, with Docker Compose or Helm. You choose the location.
Languages5 languages: English, German, French, Spanish, Brazilian Portuguese
HinSchG deadlinesAcknowledgement within 7 days and feedback within 3 months (§ 17), counted per case
EncryptionEach report has its own data key; the master key is never in the database
Reporter accountsNone: a case number and a UUID4 PIN, shown once, no email address
Audit logEvery action in the admin area; no page edits or deletes an entry

Features

What each side gets

For the whistleblower
ModeAnonymous, or confidential: name and contact encrypted, shown to the case handler only after an audited reason
Follow-upRead replies and send messages at /status with case number and PIN
For the reporting office
Case workStatuses, assignment, internal notes, linked cases, PDF export
AlertsOpt-in email and webhook digests and deadline reminders
Sign-inPassword, LDAP or OIDC, then always TOTP. Enrolment is mandatory.
Compliance

Compliance by jurisdiction

EU

EU Directive 2019/1937

Private employers with 50 or more workers, financial services firms at any size, and the public sector need an internal channel. Reports are acknowledged within 7 days and answered within 3 months.

Demo or install

Try it, then run it yourself

The public demo signs you in with prefilled credentials and is wiped every 6 hours. Never enter a real report there.

Your own installation takes three commands and one edit of .env. The /setup wizard then creates the first account.

Open the demo → Installation guide →
bash — openwhistle setup
$ git clone https://github.com/openwhistle/OpenWhistle.git
$ cd OpenWhistle && cp .env.example .env
# .env: COMPOSE_FILE, SECRET_KEY, DATABASE_URL, REDIS_URL
$ docker compose up -d

# Then open https://localhost/setup with the token from the app log
FAQ

Frequently asked questions

Is OpenWhistle really free?
Yes. It is licensed under the GNU General Public License v3.0. There is no paid tier, no paid feature and no subscription. You pay only for the server you run it on.
What does a whistleblowing system cost?
Open source software such as OpenWhistle and GlobaLeaks costs no licence fee; the compared services start at €39 a month according to their providers. A managed GlobaLeaks costs from €39 billed annually, WhistlePort €69, each per month plus VAT. EQS Integrity Line states no price. As of 27 September 2026, sources in Whistleblowing software providers compared 2026.
What does a free whistleblowing system really cost?
The licence costs €0. What remains is a server, time for updates and backups, and the work of the reporting office itself. The law also requires an oral channel by telephone (§ 16 Abs. 3 HinSchG).
Is OpenWhistle open source?
Yes, OpenWhistle is open source under the GNU General Public License v3.0. The full source code is public on GitHub. You may audit it, change it and use it commercially.
Can I host it myself?
Yes, and only that way: you run OpenWhistle on your own server with Docker Compose or Helm. The project offers no hosted service. Reports stay on that server, in the EU if you put it there.
Which whistleblowing systems offer EU hosting?
Any self-hosted system runs where your server is, so in the EU too. That applies to OpenWhistle and GlobaLeaks. Among the services, Hinweisgeberportal OpenSource and WhistlePort, for example, name data centres in Germany, as of 27 September 2026 (Whistleblowing system with EU hosting).
Is OpenWhistle GDPR compliant?
The software supports GDPR-compliant operation; whether your operation complies is your responsibility as the operator. OpenWhistle stores no IP addresses, encrypts reports and deletes closed cases automatically. The record of processing, the contract with your host and, where needed, a data protection impact assessment remain your task.
Does OpenWhistle encrypt reports?
Yes. Each report has its own data key, which encrypts its text, messages and attachments at rest. The master key is never in the database. The connection to the browser runs over TLS.
Does OpenWhistle have an audit log?
Yes. The audit log records every action in the admin area, and no page edits or deletes an entry. Whoever reveals an identity gives a reason; the log records who, when and why. A CSV export is available at any time.
Does it meet the HinSchG?
It builds in what software can: the 7-day acknowledgement (§17 Abs. 1 Nr. 1), the 3-month feedback (§17 Abs. 2), contact with the reporter (§17 Abs. 1 Nr. 3), identity confidentiality (§8), documentation and its deletion after 3 years (§11). The organisation still needs an impartial reporting office and an oral channel.
Is the whistleblower anonymous?
No IP address is stored at any layer. nginx clears the client-IP headers and writes no access log, the middleware drops the peer address, no table has an IP column, and a Redis session holds only a random token. The reporter's own device and network still matter: a private window or Tor Browser helps.
Can I use OpenWhistle for my company?
Yes. The GPL-3.0 permits commercial self-hosted use. One installation can serve several organisations, each with its own reporting link. It suits companies from 50 employees, public bodies and financial firms.
When is OpenWhistle not the right choice?
When you have no server of your own and nobody to run updates and backups: then a managed service or a SaaS provider fits better. We know of no managed service for OpenWhistle. If you need more than five languages, an external audit, an ombudsperson or paid support, other providers offer it.
What are the technical requirements?
Docker 24 or newer, Docker Compose v2, 1 vCPU, 512 MB RAM (1 GB recommended), 5 GB disk, a domain and an HTTPS certificate. PostgreSQL 18 and Redis 8 are bundled in the Compose stack.
How quickly is OpenWhistle set up?
Installation takes three commands and one edit of the .env file. The wizard at /setup then creates the first account. Before that you need a server with Docker, a domain and an HTTPS certificate (installation guide).
Is there commercial support available?
No, there is no paid support tier. Community support is on GitHub Issues, where bug reports, feature requests and contributions are welcome.
How does it compare with GlobaLeaks, SecureDrop or Hush Line?
GlobaLeaks is the mature general-purpose platform, SecureDrop serves newsrooms, and Hush Line is a hosted tip line. OpenWhistle is built around the HinSchG case workflow. The comparison lists the facts, each with its source.
How do companies evaluate whistleblowing software providers?
Seven verifiable criteria separate the providers: hosting location, encryption, anonymity, HinSchG deadlines, languages, pricing model and ombudsperson service. Ask for a source per criterion, not a grade. The answers for OpenWhistle are in Whistleblowing software providers compared 2026.
Which languages does it support?
The interface is in English, German, French, Spanish and Brazilian Portuguese. It follows the browser's language until the reader picks one; that choice is kept in a cookie.

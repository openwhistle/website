Roles

RoleMay
Superadmineverything an admin may, plus, with multi-tenancy on, organisations (/admin/organisations; without it the page is a 404). Sees every organisation, whatever its own org_id. The setup wizard creates one.
Admineverything, including users, categories, locations, the audit log and report deletion
Case Managerview, comment on and advance the reports assigned to them. The sidebar shows dashboard, statistics and telephone channel; no users, no deletion

Accounts are managed at /admin/users. A new account is a case manager unless another role is chosen; an unknown role is refused. The last active admin cannot be deactivated, so nobody is locked out. Only a superadmin creates, changes, deactivates or reactivates a superadmin. In DEMO_MODE the demo accounts cannot be changed. Only admins may dismiss the IP-header warning; the dismissal is audited.

With MULTI_TENANCY_ENABLED, /admin/system, the installation-count switch and the dismissal belong to the superadmin. An organisation's admin gets no menu entry and a 403.

The four-eyes rule has a limit. Whoever creates two accounts knows both first passwords, so one person can still act as both. The rule only refuses the maker of an account, and whoever reset it, as that account's second pair of eyes.
